Concepts in one minute

Four ideas and you've got the whole platform.

Session = conference room

Every contact is a session that participants — human and AI — join in defined roles. The session stream is the single source of truth for every event.

Agents follow a contract

agent_login → agent_ready → agent_busy → agent_done. Same contract for native (SDK) and external (sidecar) agents.

Skill Flow is declarative

Your logic lives in versioned YAML — not vendor-locked code. Inbound, outbound, automation: one engine.

MCP is the only way in

Anything that touches a business system goes through MCP — permission, injection guard, audit. No proprietary connectors.

Skill Flow

Your logic as an artifact — versioned and portable.

A state-graph interpreter with 13+ step types. State persists on every transition, and the flow is validated before it ships.

# skill_support_v1.yaml
entry: triage
steps:
  - id: triage
    type: reason # calls the LLM (BYO)
    output_schema: { intent: string }
    on_success: decide
  - id: decide
    type: choice # branches by JSONPath
    conditions:
      - { field: "@ctx.intent", eq: billing, next: billing }
    default: human
  - id: human
    type: task # delegates to a pool (human or AI)
    pool: support_l2

The step types:

taskchoicecatchescalatecompleteinvokereasonnotifymenususpendcollectresolvereceivebegin/end_transaction

Deploy lifecycle: saving creates a draft; publishing rolls out per pool with hot deploy (no restart), rollback, and scheduled deploys — draining in-flight contacts gracefully.

MCP + interception guard

One integration — audited by design.

Agents never touch a business system directly — only through authorized MCP Servers. Every call clears three checks in under a millisecond.

① Permission

The token is decoded locally — the tool runs only if the role is allowed.

② Injection guard

Heuristic patterns catch prompt injection before the call ever leaves.

③ Audit

An immutable record — server, tool, allowed, injection, duration. Policy is per tool. No opt-out.

🔌 Two mechanisms, one contract: native agents use an in-process interceptor (@plughub/sdk); external agents use a proxy sidecar on localhost. LangGraph, CrewAI, plain Python — they plug in with no code changes.

BYO LLM · AI Gateway

Bring your own model. Swap it without touching the agent.

Multi-account

Run several accounts and keys (Anthropic, OpenAI, Google…), each with its own RPM/TPM limits.

Fallback & rotation

When a key throttles (429/529), the Gateway switches accounts — and providers if it has to — without the agent noticing.

Model profiles

realtime, balanced, evaluation (isolated) — pick the model per task, not per product.

⚙️ Paired with Skill Flow's deterministic logic, you get predictable behavior and AI costs you can control — the agent names its accounts and fallbacks; limits are managed per account.

SDK & portability

Easy to get in. Free to get out.

  • SDK in TypeScript and Python, with a stable execution contract.
  • Bring your own agent (LangGraph, CrewAI, Python) as a participant — no rewrite to adopt it.
  • Move it to native with regenerate when you want the full toolkit (3 levels, suspend/resume, delegate).
  • Anti-lock-in, four ways: BYO LLM · MCP-only integration · portable YAML logic · data export.
  • verify-portability and certify prove you're free to leave.
