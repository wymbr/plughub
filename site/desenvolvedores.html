Conceitos em um minuto

Quatro ideias e você já entende a plataforma.

Sessão = sala de conferência

Todo contato é uma sessão onde participantes (humanos e IA) entram com papéis. O stream da sessão é a fonte única de verdade dos eventos.

Agente segue um contrato

agent_login → agent_ready → agent_busy → agent_done. Mesmo contrato para agente nativo (SDK) e externo (sidecar).

Skill Flow é declarativo

A lógica vive em YAML versionável — não em código preso ao fornecedor. Inbound, outbound e automação no mesmo motor.

MCP é a única integração

Tudo que toca sistema de negócio passa por MCP, com permissão, guarda anti-injeção e auditoria. Sem conectores proprietários.

Skill Flow

Sua lógica como artefato — versionável e portável.

Um interpretador de grafo de estados com 13+ tipos de passo. O estado é persistido a cada transição, e o fluxo é validado antes de publicar.

# skill_atendimento_v1.yaml
entry: triagem
steps:
  - id: triagem
    type: reason # chama o LLM (BYO)
    output_schema: { intencao: string }
    on_success: decidir
  - id: decidir
    type: choice # ramifica por JSONPath
    conditions:
      - { field: "@ctx.intencao", eq: cobranca, next: cobranca }
    default: humano
  - id: humano
    type: task # delega a um pool (humano ou IA)
    pool: suporte_n2

Os tipos de passo:

taskchoicecatchescalatecompleteinvokereasonnotifymenususpendcollectresolvereceivebegin/end_transaction

Deploy lifecycle: salvar cria draft; publicar (published) aplica por pool com hot deploy (sem restart), rollback e deploy agendado — drenando contatos em andamento (graceful).

MCP + interception guard

Uma integração só — e auditada por construção.

Agentes nunca tocam um sistema de negócio diretamente; só via MCP Servers autorizados. Toda chamada passa por três checagens, em menos de 1ms.

① Permissão

Validação de permissão por decode local do token — a ferramenta só roda se o papel pode.

② Guarda anti-injeção

Padrões heurísticos bloqueiam prompt injection antes de a chamada sair.

③ Auditoria

Registro imutável (server, tool, permitido, injeção, duração). Política por ferramenta — sem opt-out.

🔌 Dois mecanismos, mesmo contrato: agente nativo (interceptor in-process via @plughub/sdk) e agente externo (proxy sidecar em localhost) — LangGraph, CrewAI ou Python genérico entram sem alterar código.

BYO LLM · AI Gateway

Traga o seu modelo. Troque sem tocar o agente.

Multi-conta

Administre várias contas/chaves (Anthropic, OpenAI, Google…) com limites próprios de RPM/TPM.

Fallback & rotação

Em throttle (429/529), o Gateway troca de conta e, se preciso, de provedor — sem o agente perceber.

Perfis de modelo

realtime, balanced e evaluation (isolado) — você escolhe o modelo por tarefa, não por produto.

⚙️ Combinado com a lógica determinística do Skill Flow, isso dá comportamento previsível e custo de IA controlado — o agente designa contas e fallbacks; os limites são administrados por conta.

SDK & portabilidade

Entre fácil. Saia quando quiser.

  • SDK em TypeScript e Python, com contrato de execução estável.
  • Traga seu agente (LangGraph, CrewAI, Python) como participante da sessão — adoção sem reescrever.
  • Migre para nativo com regenerate quando quiser destravar tudo (3 níveis, suspend/resume, delegate).
  • Anti-lock-in por 4 vias: BYO LLM · integração só por MCP · lógica em YAML portável · export de dados.
  • verify-portability e certify atestam que você não está aprisionado.

# CLI do SDK
$ plughub-sdk certify # valida o contrato de execução
$ plughub-sdk verify-portability # checa isolamento de dependências
$ plughub-sdk regenerate # agente externo → nativo
$ plughub-sdk skill-extract # extrai skill de um agente
$ plughub-sdk proxy # sidecar p/ agente externo

# resultado
✓ contrato ok  ✓ dependências isoladas  ✓ portável

↪ Importante (sem promessa falsa): um agente externo entra como participante (conferência + MCP + auditoria). As capacidades diferenciadas — modelo de 3 níveis, suspend/resume cross-canal, delegate, commerce-cards — são do Skill Flow nativo. Por isso o caminho é trazer e migrar: regenerate → nativo.
